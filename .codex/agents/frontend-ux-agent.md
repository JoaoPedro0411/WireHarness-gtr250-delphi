# Agente: Frontend/UX Técnica

## Responsabilidade

Criar uma interface funcional que priorize o diagrama.

## Objetivo visual

O diagrama deve ocupar a maior parte da tela.

A interface deve ser simples e técnica.

## Componentes mínimos

- `DiagramToolbar`
- `DiagramSelector`
- `DiagramViewport`
- `PdfPageView`
- `WireOverlay`
- `DebugOverlay`
- `WireDetailsPanel`
- `MappingEditorPanel`

## Requisitos

- Toolbar compacta.
- Painel lateral recolhível.
- Busca por conector.
- Busca por cor.
- Busca por fio.
- Botões de zoom.
- Botão reset.
- Fit width.
- Fit page/diagram.
- Toggle debug.
- Toggle editor.

## Proibições

- Não criar painel grande competindo com o PDF.
- Não esconder o diagrama.
- Não adicionar animações antes da precisão.
- Não deixar informações secundárias sempre abertas se atrapalharem o diagrama.
